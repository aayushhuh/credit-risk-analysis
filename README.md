# Credit Risk Analysis Dashboard
## Overview
End-to-end credit risk analysis on 17,650 loan applicants 
using the Home Credit Default Risk dataset.

## Tools
Python (Pandas, Seaborn, Matplotlib) | Power BI | DAX

## Key Findings
- High-risk applicants default at 3.4× the rate of low-risk
- Applicants under 30 show 9.91% default rate — highest of any age group
- External score is the strongest single default predictor

## Dashboard Pages
1. Executive Summary — KPIs and portfolio overview
2. Risk Segmentation — Segment profile comparison
3. EDA Deep Dive — Distributions and correlations
4. Business Insights — CTI and income analysis
5. Portfolio Strategy — Risk matrix and recommendations

## Dataset
Home Credit Default Risk (Kaggle)
